# Random Runner 🏃

## About the Project

Random Runner is a simple JavaScript simulation built using HTML and JavaScript. It explores randomness and movement by simulating a runner that moves around a canvas based on randomly generated decisions.

## Features

- Random movement in different directions.
- Canvas-based visual simulation.
- JavaScript classes and objects.
- Random number generation to determine movement.
- Real-time animation using a game loop.

## Technologies Used

- **HTML5** — Page structure.
- **JavaScript** — Simulation logic and movement.
- **HTML Canvas** — Visual rendering.

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Watch the runner move according to random decisions.
